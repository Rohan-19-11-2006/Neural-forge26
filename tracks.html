TRACK 01 #CODEGEN-AGENTIC

Coding & Agentic Engineering

This track is about building coding agents and developer tools — AI systems that can write, run, and test code on their own. Projects run inside Token Factory Sandboxes, giving agents a safe environment to execute and iterate on code. Think autonomous coding assistants, automated testing agents, or tools that help developers debug and ship faster.

Best Apps & Agents

An open track for building any app or agent people would genuinely use — from a productivity tool or AI copilot to a workflow that runs itself end-to-end. Solutions are powered by Nemotron models on Nebius through Token Factory: reach for Nemotron 3 Ultra when the task needs serious reasoning, and use Nano or Super for fast, everyday calls so the app stays responsive without burning credits.

TRACK 03 #SOVEREIGN-PRIVACY

Personal AI

This track focuses on building an always-on, private personal assistant that keeps the user's data under their own control. It should have persistent memory, reusable skills, access to tools and information the user chooses, and the ability to carry out tasks across daily workflows using NVIDIA open-source models, NemoClaw, and OpenShell.

TRACK 04 #EMBODIED-ROBOTICS

Physical AI

This track is for embodied and edge AI — agents that sense and act in the real world, such as robotics, IoT devices, and on-device intelligence. Solutions are powered by Nemotron, GROOT, Cosmos, and Sonic models, coordinated through an agent runtime. Live demos or recorded physical hardware runs receive high jury evaluation.
