TRACK 01 #CODEGEN-AGENTIC

Coding & Agentic Engineering

terminal

This track is about building coding agents and developer tools — AI systems that can write, run, and test code on their own. Projects run inside Token Factory Sandboxes, giving agents a safe environment to execute and iterate on code. Think autonomous coding assistants, automated testing agents, or tools that help developers debug and ship faster.

CSE IT AIDS
DEPARTMENT SPECIALIZATION ADVISORY

CSE & IT participants are expected to demonstrate sandboxed AST mutation security and reproducible deterministic tests on synthetic commits.

TRACK 02 #FRONTIER-NEMOTRON

Best Apps & Agents

hub

An open track for building any app or agent people would genuinely use — from a productivity tool or AI copilot to a workflow that runs itself end-to-end. Solutions are powered by Nemotron models on Nebius through Token Factory: reach for Nemotron 3 Ultra when the task needs serious reasoning, and use Nano or Super for fast, everyday calls so the app stays responsive without burning through credits. Deploying via Nebius Server less Endpoints, or using Nebius Server less Jobs for background/async work, is encouraged but not required.

AIML AIDS CSE
DEPARTMENT SPECIALIZATION ADVISORY

AIML and AIDS candidates must detail latency trade-offs, token-budget dynamics, and zero-data retention proof across Nebius cluster nodes.

TRACK 03 #SOVEREIGN-PRIVACY

Personal AI

lock

This track focuses on building an always-on, private personal assistant that keeps the user's data under their own control. It should have persistent memory, reusable skills, access to tools and information the user chooses, and the ability to carry out tasks across daily workflows. Teams must use at least one NVIDIA open-source model, along with tools like NVIDIA NemoClaw, OpenShell, Hermes Agent, and Nebius Serverless to assemble, secure, and run the system.

ECE CSE IT
DEPARTMENT SPECIALIZATION ADVISORY

ECE and CSE submissions receive elevated scoring for quantizing weights (4-bit/AWQ) on consumer mobile silicon and offline fallbacks.

TRACK 04 #EMBODIED-ROBOTICS

Physical AI

precision_manufacturing

This track is for embodied and edge AI — agents that sense and act in the real world, such as robotics, IoT devices, and on-device intelligence. Solutions are powered by Nemotron, GROOT, Cosmos, and Sonic models, coordinated through an agent runtime. Nebius Serverless Jobs can be used for simulations, synthetic data generation, robot policy evaluation, or large-scale sensor data processing, while Nebius Serverless Endpoints handle real-time inference. The demo video must show at least 1 minute of the physical hardware/robot actually operating — or, if there's no physical hardware, the key application modules in action.

MECH ECE AIML
DEPARTMENT SPECIALIZATION ADVISORY

Mechanical and ECE teams should prioritize kinematic chain optimization, sensor fusion latency under 20ms, and spatial telemetry recording.
